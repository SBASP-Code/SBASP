# Dataset Instances for the Berth Allocation and Scheduling Problem

This repository contains a set of instances for the Berth Allocation and Scheduling Problem (with stochastic/uncertain elements). Each instance file (e.g., `SBASP_2_100_1_0.txt`) is formatted as a series of C++ variable declarations and initializations, making it easy to parse or include directly into C/C++ source code.

## File Naming Convention
*(You can customize this section based on your actual naming convention, e.g., `SBASP_[Vessels]_[Scenarios]_[T]_[Code].txt`)*

## Data Structure and Variables

The data in each file is organized into several categories: global dimensions, vessel/berth characteristics, fuel and emission parameters, scenario-based stochastic parameters, cost parameters, and real/predicted evaluation metrics.

### 1. Global Dimensions and Indices
* `CODE` (int): Code index for the specific instance.
   CODE = 0: Stochastic Optimization-Machine Learning Sampling (instances for PS)
   CODE = 1: Stochastic Optimization-Empirical Sampling (instances for ES)
   CODE = 2: Machine Learning-Predicted Time (instances for PD)
   CODE = 3: Expected Time (instances for ED)

* `CNN` (int): Case index.
* `T` (int): Length of the planning period (in days).
* `I` (int): Total number of vessels.
* `B` (int): Total number of berths.
* `S` (int): Number of scenarios used for stochastic programming/evaluation.
* `OS` (int): Original number of scenarios in the corresponding instance with CODE = 0 and 1 (equals `S` when CODE = 0 and 1).

### 2. Berth and Vessel Characteristics
* `br[B][S]` (int): The ready time of each berth under each scenario (in minutes).
* `vbm[I][B]` (int): A binary matrix indicating berth compatibility. `1` means the vessel can be handled at the corresponding berth, `0` otherwise.
* `Vtime[I]` (int): The total estimated visiting time for each vessel (in minutes).

### 3. Fuel Consumption and Emissions
* `Apara[I]` (double): The $\alpha$ (alpha) parameter for calculating the main engine's fuel consumption (kg per minute).
* `Bpara[I]` (double): The $\beta$ (beta) parameter for calculating the main engine's fuel consumption.
* `Gpara[I]` (double): The parameter for calculating the auxiliary engine's fuel consumption (kg per minute) while at berth.
* `Dis[I]` (double): The sailing distance for each vessel to reach the port (in nautical miles, nm).

### 4. Time and Scheduling Parameters
* `Ltime[I][S]` (double): The scheduled departure times for each vessel under each scenario (minutes from zero). 
* `Stime[I][2]` (int): The range of possible sailing times for each vessel. Index `0` is the minimum time, and index `1` is the maximum time (in minutes).
* `Htime[B][I][S]` (int): The handling time for each vessel at each berth under each scenario (in minutes).
* `Pro[S]` (double): An array intended to store the probability of each scenario occurring.

### 5. Cost Parameters
* `Hcost[I][B]` (double): The handling cost for assigning a specific vessel to a specific berth (in USD).
* `Tcost[I]` (double): The base tardiness cost penalty for each vessel (in USD per minute).
* `SLP` (double): The superlinear tardiness parameter used to scale the tardiness penalty.
* `Dcost[I]` (double): The fuel cost for each vessel (in USD per kg).
* `Ecost[I][2]` (double): The emission costs (in USD per kg of emissions). Index `0` corresponds to the main engine, and index `1` corresponds to the auxiliary engine.

### 6. Realized and Predicted Values (For Simulation/Evaluation)
These parameters represent the "ground truth" (real) values and the "predicted" values (e.g., generated by a machine learning model) used to evaluate the robustness of the schedules. 
* `RTBR[B]` (int): The *real* ready time of each berth (in minutes).
* `RTHT[B][I]` (int): The *real* handling time of each vessel at each berth (in minutes).
* `RLtime[I]` (int): The *real* departure times (in minutes).
* `Pbr[B][1]` (int): The *predicted* ready time of each berth (in minutes).
* `PLtime[I][1]` (double): The *predicted* departure times (in minutes).
* `PHtime[B][I][1]` (int): The *predicted* handling time for each vessel at each berth (in minutes).
